# Changelog

## 2.0.0 — Cinematic redesign and layered backend

- Refined the visual identity with warm ivory, deep forest green, sage, copper and muted gold.
- Added responsive bottom navigation for signed-in users on mobile.
- Organized backend code into configuration, storage, security, library services, HTTP routing and HTML rendering modules.
- Added login attempt throttling and stronger request validation.
- Improved catalogue search coverage and input validation.
- Preserved the seven-day lending period, three-item member limit and lending history protections.
- Added a health check, database check command, Windows/PowerShell launchers and architecture documentation.
- Expanded automated service, rendering and HTTP tests.
